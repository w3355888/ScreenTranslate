# 屏幕翻译 ScreenTranslate v1.3

把手机上英文（如 Maya / PayMaya）界面翻译成中文的小工具。国内网络已可打开 Maya，本工具专注解决**「英文界面 → 中文」**这一件事。

## v1.3 新增：多引擎级联（结合谷歌 + 有道）

翻译不再依赖单一引擎，按优先级自动降级，**任何网络环境下都有引擎可用**：

| 优先级 | 引擎 | 特点 |
|---|---|---|
| 1 | **ML Kit 离线模型**（英→中） | 无网可用、最快；需手机有 Google 服务 |
| 2 | **有道免费接口** | 国内直连秒通、无需 Key——模型没下好/无 GMS 手机的主力 |
| 3 | **谷歌免费接口** | 质量好；需能访问谷歌的网络 |
| 4 | **本地 GLM**（llama-server） | 手机与电脑同 WiFi 时可用，完全私有 |
| 5 | 原文兜底 | 以上全挂也不卡死界面 |

引擎失败自动进入 60 秒冷却再重试，不会反复撞死接口。

**同时新增两项提速**：
- **整屏批量翻译**：全屏几十段文字合并成 1 次在线请求（原来几十次），快数倍
- **翻译缓存**：同一句只翻一次，再次打开同一界面秒出中文

## 两种模式

### 模式 A · 无障碍点译（推荐，能翻 Maya 全屏的关键）
- 原理：通过系统无障碍接口**读取界面上的文字内容和坐标**（不是截屏），本地译成中文后**原地叠加**在原文位置上。
- 因为读的是文字不是像素，所以即使 Maya 设了**防截屏（FLAG_SECURE）**，也能拿到文字并翻译——这正是普通截屏类翻译软件（有道/彩云/腾讯翻译君）翻不了 Maya 全屏的根因。
- 开启：App 内点「开启无障碍点译」→ 系统设置里找到「屏幕翻译 / ScreenTranslate」并打开 → 回到 Maya，点屏幕上蓝色「译」球 → 英文原地变中文；再点「译」球或右上角「✕」关闭译层。悬浮球可拖动。

### 模式 B · 截屏 OCR（兜底）
- 截屏后用本地 OCR 识别再翻译。
- 若 Maya 开了防截屏，此模式会截到黑屏，**此时请用模式 A**。

## 离线翻译模型
- 服务开启时会**自动后台下载**离线模型；也可在 App 内手动点「下载离线翻译模型」。该模型从 Google 服务器下载（约 30MB），**首次需在能访问 Google 的网络下点一次**；下载完成后完全离线，国内随时可用。
- **模型没下载好也能用**：v1.3 起会自动走有道在线翻译（国内直连、无需 Key），体验无缝。
- 若你的手机**没有 Google 服务框架（GMS）**（如部分华为/鸿蒙机型），ML Kit 会失败，此时自动走有道/谷歌在线引擎；想完全私有可打开 `app/src/main/java/com/example/screentranslate/Translator.kt`，把 `LOCAL_ENDPOINT` 填成你电脑上 llama-server 的局域网地址（如 `http://192.168.x.x:8080/v1/chat/completions`，手机与电脑同一 WiFi）。

## 权限说明
- 模式 A（推荐）：只需开启无障碍服务 + 悬浮窗权限。
- 模式 B（兜底）：需授予悬浮窗 + 截屏权限；Maya 防截屏时会黑屏，请改用模式 A。

## 构建 APK
不能在本机直接编译（环境无 Android SDK）。两种办法：
- **GitHub Actions（推荐，零安装）**：把整个 `ScreenTranslate` 目录推到 GitHub 仓库，`build.yml` 会自动编译并在 Actions 的 Artifacts 里产出 `app-debug.apk`。详见 `BUILD_VIA_GITHUB.md`。
- 本机 Android Studio：用 Android Studio Ladybug / Koala 以上版本打开本目录，`Build → Build Bundle(s) / APK → Build APK`。

## 快速替代方案（先试这个）
如果你只是想翻 Maya 屏幕，**先试系统自带的 Google 翻译 App 的「点按翻译」**：打开 Google 翻译 → 设置 → 点按翻译 → 开启。它和本工具的模式 A 是同一套机制（无障碍读字 + 离线翻译），而且是大厂久经考验的实现。如果它已经能在 Maya 上翻译，你就不一定需要装这个自建 App 了。本工具的价值在于：可定制、能接你本地 GLM、无广告、完全离线可控。
